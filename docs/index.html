// install

Open the door in three steps.

Download and drag

Download Cellar.dmg, open it, and drag Cellar into Applications. One download for Apple silicon and Intel Macs.

Open it the first time

Cellar is free and isn't signed with a paid Apple developer account yet, so macOS asks once:

  1. Open Cellar. When macOS says it can't verify it, click Done.
  2. Go to System Settings › Privacy & Security.
  3. Scroll down and click Open Anyway, then confirm.

After that it opens like any other app. If macOS offers to install its free Command Line Tools, accept: Cellar uses the Python that comes with them.

Plug in your phone

On the phone: Settings › About phone › tap Build number seven times, then Developer options › USB debugging. Plug in and tap Allow. Cellar offers to download Android's tools if your Mac doesn't have them.

Rather build it yourself? git clone https://github.com/hystericmoon/cellar, then double-click Build Mac App.command. A copy built on your Mac opens without the Open Anyway step.
